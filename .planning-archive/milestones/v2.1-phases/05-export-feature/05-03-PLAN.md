  <action>
Add Obsidian export implementation to the professor:export section in agents/professor.md:

1. **Vault path management**:
   - Check for existing vault path in `.export-config.json` (create if doesn't exist)
   - If not set → Use AskUserQuestion:
     > "What's the path to your Obsidian vault?"
     > User provides absolute path (e.g., /Users/name/Documents/Obsidian/MyVault)
   - Save to `.export-config.json` for future exports
   - Validate path exists before proceeding

2. **After MCP availability confirmed** (in the Obsidian branch):

3. **Create folder structure**:
   - Path: `/{vault}/{course-slug}/`
   - Create course folder via MCP (obsidian_create_folder or equivalent)

4. **Create Markdown files** with YAML frontmatter:

   a. **course.md** (course overview):
      ```markdown
      ---
      title: "Course: {Topic Name}"
      date: {export-date}
      tags: [course, {topic-slug}, learning]
      course-slug: {topic-slug}
      status: {in-progress|completed}
      level: {level}
      progress: "{X/Y sections complete}"
      ---
      
      # Course: {Topic Name}
      
      ## Learning Objectives
      ...
      
      ## Syllabus & Progress
      | # | Section | Status |
      |---|---------|--------|
      ...
      ```

   b. **lecture-1.md, lecture-2.md, ...** (one per section):
      ```markdown
      ---
      title: "Section N: {Section Title}"
      date: {date}
      tags: [lecture, {topic-slug}]
      course-slug: {topic-slug}
      ---
      
      # Section N: {Section Title}
      
      ## Concept
      ...
      
      ## Exercise
      ...
      ```

   c. **notes.md**:
      ```markdown
      ---
      title: "Notes: {Topic Name}"
      date: {export-date}
      tags: [notes, {topic-slug}]
      course-slug: {topic-slug}
      ---
      
      # Notes: {Topic Name}
      
      {All content from NOTES.md}
      ```

   d. **capstone.md**:
      ```markdown
      ---
      title: "Capstone: {Project Name}"
      date: {export-date}
      tags: [capstone, {topic-slug}]
      course-slug: {topic-slug}
      ---
      
      # Capstone Project: {Project Name}
      
      {Full CAPSTONE.md content}
      ```

   e. **summary.md**:
      ```markdown
      ---
      title: "Learning Summary: {Topic Name}"
      date: {export-date}
      tags: [summary, {topic-slug}]
      course-slug: {topic-slug}
      ---
      
      # Learning Summary: {Topic Name}
      
      ## Completed Sections
      - Section 1: {Title} ({date})
      ...
      
      ## Key Concepts Learned
      - {concept 1}
      - {concept 2}
      
      ## Capstone Project
      {capstone description}
      
      ## Recommendations
      - {recommendation 1}
      ```

5. **MCP tool calls**:
   - obsidian_create_folder for course folder
   - obsidian_create_note for each .md file (or obsidian_write_note)

6. **Success message**:
   > "Export complete! Your course is now in Obsidian at:
   > - {vault}/{course-slug}/course.md
   > - {lecture files}
   > - notes.md, capstone.md, summary.md
   > 
   > Run professor:export again anytime to re-export."

7. **Error handling**:
   - If vault path invalid → prompt for correct path
   - If MCP call fails → show error and offer retry
   - Wrap in try/catch

8. **Add config file to .gitignore** if not already:
   - Ensure `.export-config.json` is gitignored (secrets/path)
