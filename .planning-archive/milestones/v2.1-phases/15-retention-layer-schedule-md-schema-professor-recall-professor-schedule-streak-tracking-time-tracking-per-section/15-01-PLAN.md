  <action>
Add SCHEDULE.md schema specification to agents/professor.md in the File Structure section:

**SCHEDULE.md** — Spaced repetition schedule and flashcards. Created when section marked done.

```markdown
---
created: YYYY-MM-DD
updated: YYYY-MM-DD
course: {course-slug}
---

# Spaced Repetition Schedule

## Flashcard Set

| Section | Question | Answer | Last Reviewed | Next Review | Interval | Status |
|---------|----------|--------|---------------|-------------|----------|--------|
| 1.1     | What is X? | X is... | — | YYYY-MM-DD | 1 day | new |

## Review Queue

| Priority | Section | Due Date | Days Overdue | Flashcard Count |
|----------|---------|----------|--------------|-----------------|
| 🔴 High  | 1.1     | YYYY-MM-DD | 0 | 3 |
| 🟡 Medium| 1.2     | YYYY-MM-DD | — | 3 |
| 🟢 Low   | 1.3     | YYYY-MM-DD | — | 3 |

## Stats

- Total Sections: N
- Reviews Completed: N
- Current Streak: N days
- Last Active: YYYY-MM-DD
```

**Spaced Repetition Intervals:**
- New card: 1 day
- Rating "clear": double the interval (1d → 2d → 4d → 8d → 16d → 30d)
- Rating "fuzzy": same interval
- Rating "forgot": reset to 1 day

<task type="auto">
  <name>Task 2: Modify professor:done to auto-create SCHEDULE.md</name>

  <action>
Update commands/professor/done.md to include SCHEDULE.md creation:

After "Update `COURSE.md`: change section status to ✅ Done", add:

**Create or update SCHEDULE.md:**

1. Check if SCHEDULE.md exists in the course directory. If not, create it with:
   - Frontmatter: created, updated, course
   - # Spaced Repetition Schedule heading
   - Empty Flashcard Set table
   - Empty Review Queue table
   - Stats section with zeros

2. For the completed section, generate 3 Socratic flashcards:
   - Card 1: Conceptual question about the main topic (e.g., "What is the core purpose of X?")
   - Card 2: Application question (e.g., "When would you use X instead of Y?")
   - Card 3: Synthesis question connecting to prior knowledge (e.g., "How does X relate to [previous section concept]?")
   
3. Add flashcards to the Flashcard Set table with:
   - Section number and name
   - Question (Socratic, not giving away the answer)
   - Answer (brief, accurate)
   - Last Reviewed: "—"
   - Next Review: tomorrow's date (YYYY-MM-DD)
   - Interval: "1 day"
   - Status: "new"

4. Add section to Review Queue with:
   - Priority: 🔴 High (new items always high priority)
   - Due Date: tomorrow
   - Days Overdue: "—"
   - Flashcard Count: 3

5. Update Stats section counters

**File location:** 
- For worktree courses: `learning/{slug}/SCHEDULE.md`
- For legacy courses: `courses/{slug}/SCHEDULE.md`
