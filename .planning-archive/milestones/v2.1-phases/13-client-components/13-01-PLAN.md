# Key Technical Decisions (from RESEARCH.md)

## Libraries
- React 19.x with Vite 7.x
- react-markdown 10.x + remark-gfm for markdown rendering
- react-syntax-highlighter 16.x (Prism) for code highlighting
- DOMPurify 3.x for XSS sanitization

## Project Structure (aligned with docs/plans/2026-03-08-web-ui-implementation.md)
```
web/client/
├── index.html
├── vite.config.js
├── package.json
├── src/
│   ├── main.jsx
│   ├── App.jsx
│   ├── App.css (dark theme)
│   ├── components/
│   ├── hooks/
│   ├── utils/
│   │   └── markdown.js (DOMPurify wrapper)
│   └── api/
│       └── client.js
```

## Locked Decisions (from CONTEXT.md and docs/plans/)
- 50/50 split (lecture left, chat right) — aligned with approved design
- Dark mode theme with blue accent
- System fonts (no web font downloads)
- Command pills above chat input (like Slack)
- Course selector dropdown in top-left of header
