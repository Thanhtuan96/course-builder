<task type="auto">
  <name>Task 4: Modify professor:archive for worktree removal</name>
  <files>commands/professor/archive.md</files>
  <action>
Modify archive.md to handle worktree archive (copy files, then remove worktree).

Steps:

1. Detect course type:
   - If course in learning/{slug}/ → worktree archive mode
   - If course in courses/{slug}/ → legacy archive mode (existing behavior)

2. For worktree mode (learning/):
   a. Read source files from learning/{slug}/:
      - COURSE.md
      - NOTES.md (if exists)
      - CAPSTONE.md
   b. Check for incomplete sections (same as current)
   c. Generate SUMMARY.md retrospective
   d. Create .course_archive/{slug}/ directory
   e. Copy files to archive: COURSE.md, NOTES.md (if exists), CAPSTONE.md, SUMMARY.md
   f. Remove worktree: git worktree remove learning/{slug}/ --force
   g. Delete the branch: git branch -D learning/{slug}

3. For legacy mode (courses/):
   Keep existing behavior (exercises remain, folder deleted).

4. Archive path handling:
   - Primary: .course_archive/{slug}/
   - If exists: .course_archive/{slug}-{YYYY-MM-DD}/
  </action>

<automated>cat commands/professor/archive.md | grep -q "learning/"</automated>
  </verify>
