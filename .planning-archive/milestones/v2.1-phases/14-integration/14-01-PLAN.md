<task type="auto">
  <name>Task 1: Create Express server with static file serving</name>
  <files>web/server.js</files>
  <action>
Create Express server at web/server.js that:
- Uses Express, cors, http modules
- Sets PORT from process.env.PORT (default 3000)
- Sets NODE_ENV from process.env.NODE_ENV (default 'development')
- Reads ANTHROPIC_API_KEY, CLAUDE_API_KEY, or OPENAI_API_KEY from environment
- GET /api/courses - lists all courses from ./courses/ directory (reads COURSE.md files for metadata)
- GET /api/courses/:slug/:file - returns content of COURSE.md, LECTURE.md, NOTESONE.md
-.md, CAPST POST /api/courses/:slug/:file - saves content to course files
- POST /api/chat - streams Claude responses via SSE
- POST /api/notify - triggers WebSocket broadcast
- In production (NODE_ENV=production): serves static files from web/client/dist/ via express.static
- In development: proxies /api to port 3000, serves Vite dev server at /
- Includes WebSocket server for real-time lecture updates
- Uses same courses/ directory as CLI (process.env.COURSES_DIR || './courses')
  </action>
  <verify>
    <automated>node -e "import('./web/server.js').then(() => console.log('Server loads OK'))" 2>&1 | head -5</automated>
  </verify>
  <done>Express server created with all API routes, production static serving, and development proxy</done>
</task>
