<objective>
Polish the four specialized agents (Coach, Spotter, Navigator, Researcher) for cross-platform compatibility.

Purpose: These agents are subagents — invoked by Professor or directly by the user. On OpenCode, the mode: field explicitly marks an agent as a subagent vs primary agent. Without it, Coach, Spotter, Navigator, and Researcher would appear as primary conversation starters on OpenCode, cluttering the UI. Additionally, their body text contains "delegate back to Professor" language that only works on Claude Code — on other platforms the user gets confused when an agent says "handing you back to Professor" but Professor never shows up.

Output: All 4 agents polished with mode: subagent, model: inherit, and platform-agnostic return language.
</objective>
