# Phase 17.1.1.1: Navigator Agent - Context

**Gathered:** 2026-03-15
**Status:** Ready for planning

<domain>
## Phase Boundary

Create Navigator agent that helps learners see connections between sections and threads concepts across a course. Navigator appears between sections to reinforce learning by showing "what you just learned → what comes next" bridges. Depends on Phase 17.1.1 (Spotter Agent).

</domain>

<decisions>
## Implementation Decisions

### Trigger Timing
- **Hybrid approach:** Navigator appears in two modes:
  - Brief bridge after `professor:done` marks a section complete (reinforcement)
  - Fuller bridge when learner runs `professor:next` to advance to new section (preparation)

### Bridge Format
- **Learner choice:** Navigator presents three format options and learner chooses:
  - Text summary: "In Section 3 you learned X. In Section 4 you'll build on this by learning Y."
  - Concept map: Visual-style arrows showing "X → connects to → Y → enables → Z"
  - Socratic prompts: Questions that help learner discover connections themselves

### Concept Map Storage
- **LEARNING-LOG.md:** Extend existing file with "Concept Thread" section that Navigator builds over time. Keeps file structure simple and follows established pattern from Coach/Spotter.

### Insight Threading
- **Forward references:** Navigator adds entries like "Previously: Spotter helped you realize X → Now: This connects to Y" to show how previous insights carry forward to new sections.

### Claude's Discretion
- Exact wording of bridge content
- How Navigator detects "key ideas" from each section to thread
- Whether to include visual ASCII diagrams in concept map format

</decisions>
