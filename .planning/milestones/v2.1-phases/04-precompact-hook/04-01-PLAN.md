  <action>
Create hooks/pre-compact.js with the following functionality:

1. **Token Warning Display (HOK-01):**
   - Check context.tokenCount (available in PreCompact event context)
   - Define a threshold (e.g., 80% of max tokens)
   - Display a visible warning message using console.warn() with clear formatting
   - **Add a fun break reminder** (randomly selected from pool):
     - "Time for a coffee break? ☕ Your brain will thank you!"
     - "Stretch break! Your posture (and neurons) will appreciate it. 🧘"
     - "Have you hydrated today? 💧 Smart learners stay hydrated!"
     - "Maybe take a walk? Fresh air + learning = brain magic! 🚶"
     - "Your eyes need a rest from screens. Look at something far away! 👀"
     - "Pro tip: Teaching someone else what you just learned = double retention!"
     - "Fun fact: Sleep consolidates memory. Just saying... 😴"
    - Display the warning with the selected message:
      ```
      ╔════════════════════════════════════════════════════════════╗
      ║  TOKEN WARNING: Context approaching compression threshold  ║
      ║  Current: {X}% of token limit                              ║
      ║                                                             ║
      ║  💡 {fun_break_message}                                   ║
      ║                                                             ║
      ║  Your course progress will be auto-saved to COURSE.md      ║
      ╚════════════════════════════════════════════════════════════╝
      ```

2. **Session State Auto-Save (HOK-02):**
   - Find the active COURSE.md by scanning courses/*/COURSE.md for the most recently modified
   - Read the current COURSE.md content
   - Extract current session state (look for "Current Section:" or similar markers)
   - Update COURSE.md with session state including:
     - Last active section (from LECTURE.md if it exists)
     - Progress status (completed sections marked with ✅)
     - Timestamp of last save
   - Write the updated content back to COURSE.md
   - Use try/catch to handle cases where no course exists

3. **Session State Format in COURSE.md:**
   Add/update a session state section at the top of COURSE.md:
   ```markdown
   ---
   session_state:
     last_active_section: "section-name"
     last_updated: "ISO timestamp"
     lecture_summary: "brief summary of current lecture content"
   ---
   ```

Implementation notes:
- Use synchronous fs operations (fs.readFileSync, fs.writeFileSync)
- Course directory is courses/{topic-slug}/COURSE.md
- If multiple courses exist, find the most recently modified COURSE.md
- Handle gracefully if no course exists (no-op with info message)
