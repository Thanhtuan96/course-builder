## Reversibility gates

- **Gate A:** the strict meta must exist and the directive test must pass before adding the dev
  relaxation. Never satisfy dev by editing the meta itself.
- **Gate B:** the relaxer must be proven to run only for `serve`; run the production build before
  merging. CSP is deployable configuration, and the rollback is a git revert of this plan's commit.
- No data or schema changes.

  <files>studio/index.html, studio/test/settings-csp.test.js (new)</files>

  <action>
  Insert a `<meta http-equiv="Content-Security-Policy" content="…">` immediately after
  `<meta charset="UTF-8" />` and before the viewport/favicon/title/script tags. Use exactly this
  policy, with a single space after each semicolon:
  `default-src 'self'; script-src 'self' 'wasm-unsafe-eval' https://cdn.jsdelivr.net; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self' data:; connect-src 'self' http://localhost:* http://*.localhost:* http://127.0.0.1:* https://localhost:* https://*.localhost:* https://127.0.0.1:* https://api.anthropic.com https://api.openai.com https://openrouter.ai https://api.groq.com https://cdn.jsdelivr.net; object-src 'none'; base-uri 'none'; form-action 'self'`.
  Do not add `frame-ancestors`, `'unsafe-eval'`, or a script `'unsafe-inline'`.
  Create `test/settings-csp.test.js` (owned via `settings*.test.js`) reading `../index.html`: assert
  the meta exists inside `<head>` before the first `<script`, each directive and source above is
  present, `script-src` contains `'wasm-unsafe-eval'` and `https://cdn.jsdelivr.net`, `connect-src`
  contains the loopback http expressions plus their https forms, `'*.localhost'`, and no IPv6 host-source, the four
  provider origins and the CDN, and that the content has no exact `'unsafe-eval'` token and no
  `frame-ancestors`.
  </action>
  <acceptance_criteria>
  - The meta is the first policy-bearing tag and precedes every script.
  - All locked directives/sources exist; the exact quoted token `'unsafe-eval'` is absent.
  - `frame-ancestors` is absent.
  - The favicon data URI still needs `img-src data:`, and the test proves it is allowed.
  </acceptance_criteria>
  <verify>
    <automated>npm --prefix studio test -- --run test/settings-csp.test.js</automated>
    <fails_when>Non-zero exit, 0 passed, or a failure message naming a missing directive/source, an unexpected `'unsafe-eval'`, or an unexpected `frame-ancestors`.</fails_when>
  </verify>
