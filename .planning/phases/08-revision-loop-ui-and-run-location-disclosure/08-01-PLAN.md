## Test harness facts that shape every test file

- Studio project include is `test/**/*.test.js` — the file must end in `.test.js`; write JSX with `createElement`, never `.test.jsx`.
- Components are rendered with `renderToString(createElement(Component, props))` from `react-dom/server`; no DOM, no effects run.
- Repo tests install `repo.useAdapter(createMemoryAdapter())` in `beforeEach` and use `vi.useFakeTimers()` + `vi.setSystemTime` when timestamps matter.
- `renderToString` has no `localStorage`: every ack helper takes an injectable `storage` argument, and tests pass a fake (`{ getItem, setItem }`) or `null`.
- The English catalog is the default (`settings.language` default), so SSR text assertions are English unless a test explicitly switches language.
- `t('missing.key')` returns the raw key — a test asserting English copy therefore also fails loudly when a catalog key is missing.
