<objective>
Make `shared/` a generated artifact that cannot silently diverge from its canonical sources, and add
the guard that fails when it does.

Purpose: installers read `shared/` directly (`bin/platforms/claude.js`, `gemini.js`, `cursor.js`),
while authors edit `agents/`, `commands/professor/`, `hooks/pre-compact.js` and

missing the Agent Architecture section, so installed users already get stale content. One sync script
plus a drift test closes that class of failure (D-01, D-02, D-07).

`bin/sync-shared.sh` wrapper, a fully regenerated `shared/` tree, version-aligned plugin manifests,
and `test/shared-drift.test.js`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| canonical files -> sync script | Repo-controlled content is read; a committed symlink or path-like entry could redirect a destination outside the managed tree. |
| sync script -> `shared/` | The script creates, overwrites and deletes files under managed directories; an over-broad sweep could remove unmanaged content. |
| shell wrapper -> Node CLI | User arguments cross from `bin/sync-shared.sh` into the script; unsafe quoting could alter command execution. |
| manifests <-> filesystem | Declared command/agent/hook paths must correspond one-to-one with real canonical files. |
