  Create `web/security.js` as the single home for token file operations (D-14). Export:
  `PROFESSOR_HOME`, `tokenFilePath(env)`, `legacyTokenPath(repoRoot)`, `readTokenFile(file)`,
  `writeTokenFile(file, token)`, `ensureStudioToken({ env, home, legacyFile, log })`,
  `migrateLegacyToken({ env, legacyFile, file })`, `maskToken(token)`,
  `createTokenGetter({ env, home, legacyFile, log })` and
  `rotateStudioToken({ env, home, legacyFile, log })`.
  Behaviour:
  - Resolution order is `STUDIO_BRIDGE_TOKEN` → existing `tokenFilePath(env)` → one-time migration of
    `web/.studio-token` → `randomBytes(24).toString('hex')` (D-01, D-02).
  - `writeTokenFile` creates the directory with mode 0700, writes a sibling temp file with
    `mode: 0o600`, chmods the temp, renames atomically, then chmods the final path so a pre-existing
    0644 file becomes 0600 (D-01; research §3.2).
  - Migration only runs when there is no env override and no new token file; it writes the new file
    first, then deletes the legacy file. If the new file already exists, the legacy file is left
    untouched (D-02).
  - `maskToken` returns a fixed-width first-four/last-four form and never the full token (D-05).
  - `rotateStudioToken` generates a new token and writes it atomically; it throws `code:
    'env_token_immutable'` when `STUDIO_BRIDGE_TOKEN` is set and writes nothing (D-23).
  - `createTokenGetter` caches `{ token, mtimeMs, size }` and re-reads when `statSync` reports a
    change, so an in-flight server observes rotation without a restart (D-23).
  Do not print the token; callers own banners. Keep the module Node-18-compatible.
  Every file operation takes its root from the injected `home`/`env`/`file` argument; the module
  itself must never call `homedir()` or otherwise fall back to the real `~/.professor` when a
  caller supplied a temp root.
  </action>
  <acceptance_criteria>
    - `web/security.js` exports every symbol listed above (and no route/middleware factories yet).
    - A fresh call with an empty `PROFESSOR_HOME` creates `studio-token` with 0600 and 48 hex chars.
    - A pre-existing 0644 token keeps its content and becomes 0600 after `ensureStudioToken`.
    - `STUDIO_BRIDGE_TOKEN` short-circuits file creation entirely.
    - With `home`/`env.PROFESSOR_HOME` pointing at a temp dir, no helper reads or writes the real
      `~/.professor`; an absent explicit root is the only way `homedir()` is consulted.
    - `maskToken('abcdefghijklmnop')` is not equal to the input and contains the first four/last four.
  </acceptance_criteria>
  <verify>
    <automated>node -e "import('./web/security.js').then(m=>{const need=['tokenFilePath','ensureStudioToken','maskToken','createTokenGetter','rotateStudioToken','writeTokenFile'];for(const k of need)if(typeof m[k]!=='function')throw new Error('missing '+k);const t=m.maskToken('abcdefghijklmnop');if(t==='abcdefghijklmnop')throw new Error('unmasked');console.log('ok')})"</automated>
    <fails_when>Any required export is missing, or maskToken returns the input unchanged.</fails_when>
