## Assumptions (unresolved probe rows, stated not silently resolved)

The probe left PW-03's requirement row `unclassified` because no SPEC.md exists. Assumptions taken
from `09-CONTEXT.md` D-04/D-05/D-18 and `09-RESEARCH.md` §F, each mapped to a truth above:

- A1: the normalized shape is the D-04 shape **plus** additive keys (`schemaVersion`, `reporter`,
  `stats.projects`, `stats.chromium`, `excerpt`) — additive keys are allowed, existing D-04 keys must
  always be present. → artifacts/exports + `key_links`.
- A2: no Playwright version is not a warning (pasted list text has none). → truth 1 + list tests.
- A3: "mismatch" means exactly the closed warning-code set; `unknown_spec_files` and
  `claimed_pass_with_failures` are computed on demand from the submission (they are **not** parser
  output because the parser never sees the learner's files). → `evidenceWarnings` export.
- A4 (**deliberate divergence from RESEARCH §F**): RESEARCH's edge table classifies a mixed
  `--reporter=list,json` paste as `format: 'list'` and ignores the embedded JSON. This plan instead
  anchors on the reporter's fixed `{\n  "config":` anchor (RESEARCH §F "JSON detection (tolerant,
  ordered)") and classifies it as `format: 'json'`, because the JSON report carries the authoritative
  per-test counts while list rows are lossy. The UI never suggests the mixed recipe (D-16/A1 in
  09-04), so this only softens a paste the learner produced on their own; truth 3 and the
  `mixed-list-json` fixture pin the chosen behaviour, and no double counting is allowed.

## Reversibility gates

- **Gate A (after Task 1):** fixtures only — nothing imports them yet, so a wrong fixture shape is a
  free revert. Confirm every fixture parses under the researched regexes before writing the parser.
- **Gate B (after Task 2, tracer):** the JSON path end to end (pass + fail fixtures) must be green
  before the list/line path is added. The stored payload shape is a **one-way** cross-phase contract
  (D-04); if the shape has to change, change it here, not after other plans consume it.
- **Gate C (before Task 3 finishes):** the 32 KB serialized cap (enforced by the clamp inside
  `parseEvidence`, proved by the hostile 400-test input) and the "no attachments/stdout/stderr"
  assertion (on the structured payload, excluding the deliberately-raw `excerpt`) must both pass.
  Storing an unbounded paste is the phase's privacy regression.
