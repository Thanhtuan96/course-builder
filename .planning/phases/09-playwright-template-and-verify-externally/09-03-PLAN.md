## Edge Coverage and Assumptions

- PW-02 and PW-04 are `unclassified` probe rows (no SPEC.md). Their edges are fixed here explicitly:
  - **Judgement vs fact:** R1/R2/R3/R5/R7 stay model judgements over code-generated facts; R4 and R6
    have deterministic clamps; only R6 (plus failed counts, blocking warnings) can force the verdict.
  - **Empty:** zero criteria, zero tests, zero spec files and unknown format all resolve to
    `needs_work` — never to a default pass.
  - **Adjacency:** a criterion the model omits is filled from the rubric key with status `not_met` and
    a code-owned question (never silently dropped, never invented as `met`).
  - **Ordering:** criteria are emitted in rubric order regardless of the model's order.
  - **Encoding:** tag-shaped sequences in any language/whitespace variant (`< / external_evidence >`)
    are neutralised; `neutralizeDelimiters` matches case-insensitively with optional inner spaces.
  - **Concurrency:** every function here is pure/synchronous over its arguments — no module state.
- Assumption A1: R4's clamp floor is `partial` (D-22), not `not_met`, because regex facts can misfire
  even after the pre-pass; the model may still downgrade.
- Assumption A2: `count_mismatch` blocks because it means the paste is internally inconsistent — a
  self-reported report the learner cannot reconcile is not evidence.

## Reversibility gates

- **Gate A (after Task 1, tracer):** `computeCapstoneFacts` + `capstoneEvidenceMode` must be green on
  one clean spec and one dirty spec (hard wait + force + coordinate click + CSS locator) before the
  prompt work starts. The facts shape is consumed by UI plans 09-04/09-06 — changing it later is a
  cross-plan edit.
- **Gate B (before Task 3 finishes):** the injection test must pass **with the model stubbed as fully
  obedient** (all `met`, `verdict: 'course_complete'`). A green injection test that relies on the model
  refusing proves nothing; do not weaken it to "the prompt asks the model to refuse".
- **Gate C:** the existing in-app tests (`capstone.test.js`, `prompts-capstone.test.js` pre-existing
  cases) must be green at every commit — this plan adds a branch, it does not replace the in-app path.
