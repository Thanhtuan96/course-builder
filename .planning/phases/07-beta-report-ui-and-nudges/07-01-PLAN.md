seam exists so plan 07-02's "exporting silences today's reminder" marker lands on the path the learner
actually uses, not on a test-only helper.

`__APP_VERSION__` define in `studio/vite.config.js`, the `DataPanel` mount, and
`studio/test/beta-report-panel.test.js`.

## Reversibility gates

- **Gate A (costly — D-10, one-way in practice):** the filename template
  `professor-beta-report-<pid8>-d<N>.json` and the in-JSON `participantId` are the contract Phase 10's
  aggregation and the beta kit documentation are written against. Implement them exactly; do not add a
  timestamp, do not shorten the pid to fewer than 8 characters, and do not change the extension. Any
  change needs orchestrator sign-off, not an executor decision.
- **Gate B (reversible):** the `__APP_VERSION__` define is one line plus one exported constant. If
  `vite build` or the root aggregate surprises us, revert the define and the `appVersion()` fallback
  still yields `''` — the report stays schema-valid.
- **Gate C (reversible):** the `betaReport` namespace files are additive. Reverting them removes the
  panel copy only; no other namespace is touched, so no existing screen can regress.
- **Do not** "fix" a missing `define` by editing `vitest.config.js` (Phase 4 owns it) — the guard in
  `appVersion()` is the contract.
