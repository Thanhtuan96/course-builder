## Reversibility gates

- **Gate A (cheap, reversible):** the marker key shape
  `professor-studio:beta-report-{dismissed|exported}:<offset>` and the `?report=1` query marker. Both are
  local-only; changing either after the beta starts only resets dismissal state. Keep the
  `beta-report` element id and the `?report=1` value stable anyway, because the Home banner and
  `Settings.jsx` are coupled through them.
- **Gate B (costly, one-way in practice):** the reminder semantics — offsets exactly 7 and 14, dismissal
  per checkpoint, export silences the current checkpoint. Phase 10's check-in script and threshold doc
  assume Day-7 and Day-14 exports. Do not broaden to "every day" or "offset ≥ 7"; that needs
  orchestrator sign-off.
- **Do not** add a repository table, event kind or migration for dismissals (D-13/D-14). If persistence
  feels wrong, the correct move is to keep it in `localStorage`, not to add a write.
