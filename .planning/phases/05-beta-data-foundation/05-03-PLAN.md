<objective>
Store revision links at the repository layer: explicit `revisionOf` links when the UI supplies them
and deterministic same-artifact inference with a 72-hour window when it does not.

Purpose: INSTR-04 and D-06/D-07 make revision-after-feedback a first-class countable action. Phase 5
stores the links now with no UI callers; Phase 8 wires the "Revise" surface and Phase 9 passes
capstone checkpoint links. The `revisionOf` parameter shape and `revision_links` columns are frozen.

Output: `events.js` revision builders/predicates, `maybeLinkRevision` in `repo/index.js`, explicit
and inferred links for quiz/tutor/workspace/capstone, `listRevisionLinks`, and positive plus negative
tests.
</objective>
