## Mandatory plan-level checkpoints

- **P1 - inner checks discrimination:** a UI-shaped run with `checks: { checks: [], snapshot }`
  emits `workspace_run`; a non-empty inner array emits `exercise_completed`; never both. Verified in
  05-02.
- **P2 - `dayKey('YYYY-MM-DD')` day-shift:** under `TZ=America/Los_Angeles`,
  `dayKey(new Date('2026-01-01T23:30:00')) === '2026-01-01'` and the component-based offsets give 0
  for the same local day and 1 for the next local day; the failing direction is a UTC slice
  storing `2026-01-02` or a re-parse shifting the stored day. Verified in 05-04.
- **P3 - studio-api schemaVersion:** `/db/health` reports 5 after 0005; the old `1` assertion is the
  failing direction. Verified in 05-01.
