    exactly `{ activation: { activated, firstEventKind }, generatedAtDayOffset, window: {

    - `week2Return`: any offset in 8-14.
    - `week2MeaningfulDays`: count of distinct local `day` values whose offset is 8-14.
    - `generatedAtDayOffset`: `dayOffset(dayKey(now), profile.activated_day)` clamped at 0.
