<objective>
Close Gap G-01 / MH-11 by making the explicit revision-link contract identical in the DDL, the pure builder and every storage adapter.

Purpose: an explicit `revisionOf` with a valid feedback row but no prior attempt currently writes `attempt_id: null`, which succeeds on memory/IndexedDB and throws `NOT NULL constraint failed: revision_links.attempt_id` on SQLite. Because `0005_beta_loop.sql` has not merged, the user chose to allow NULL in the unreleased DDL, re-pin its hash and prove the case on all three adapters.

Output: nullable `attempt_id` in 0005 with a documenting comment, a matching SHA-256 pin, null-attempt assertions on fresh/upgrade SQLite, and one cross-adapter explicit-without-prior regression test for memory, IndexedDB and SQLite.
</objective>
