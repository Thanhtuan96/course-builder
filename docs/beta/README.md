# Beta kit

Everything the owner needs to run a 3–5 person macOS beta: recruit, onboard, check in, aggregate the
reports and decide.

## Owner

- [Check-in script](owner/CHECK-IN-SCRIPT.md) — the four fixed check-ins, the three behavioural questions and the record table.
- [Thresholds](owner/THRESHOLDS.md) — the metric formulas, the continue/change/stop rule and the draft sign-off block.
- [Decision memo template](owner/DECISION-MEMO-TEMPLATE.md) — the document filled in after Day 14 to record the outcome.
- [Aggregation](owner/AGGREGATION.md) — how to run the report aggregator, read its columns and interpret its exit codes.

## Participant

- [Onboarding](participant/ONBOARDING.md) — the one-pager a participant reads before Day 0.
- [Screener](participant/SCREENER.md) — one copy-paste checklist for the knockout questions and fit signals.
- [Consent](participant/CONSENT.md) — the paragraph to send, plus what is and is not collected.
- [Troubleshooting](participant/TROUBLESHOOTING.md) — pairing token, start and port problems, runner limits and export.

## Before Day 0

- Sign the thresholds: fill the `## Sign-off` block in `owner/THRESHOLDS.md` so the numbers are frozen before any data exists.
- Screen each candidate with `participant/SCREENER.md` and accept only on the written rule.
- Get a written yes to the `participant/CONSENT.md` paragraph.
- Create the shared reports folder that will hold the exports.
- Put the roster file in that folder so a participant without an export still shows up.

The whole kit is English only for this cohort; a translation can be added later without changing the
layout.
