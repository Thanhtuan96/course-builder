# Consent

Send the paragraph below as one message, then keep the two lists as the answer to "what exactly do
you collect?".

## Sendable paragraph

> Professor private beta consent: this is a four-week private beta of Professor, a local Socratic learning tool for macOS. You can stop at any time and ask me to delete your files. The beta reports are local JSON files that you export and send to me by hand; nothing is uploaded automatically.

## What is collected

- Activation: whether you activated, on which local day offset, and the kind of your first meaningful event.
- Active local days: the list of day offsets, counted from your activation day, on which you did something.
- Practice loop counts by kind: quiz completed, recall completed, answer sent for review, workspace run, exercise completed and capstone checkpoint.
- Revision counts: per surface, and how many links were explicit versus inferred.
- Week-1 and week-2 activity: whether you were active in week 1, whether you returned in week 2, and how many week-2 days held a meaningful action.
- Capstone checkpoints: whether you started, how many submissions and pieces of external evidence exist, and the verdict.

The report holds counts and category labels only. If a detail is not in the list above, it is not in
the report.

## What is not collected

- Course text, lesson content and lecture content.
- Prompts, chat messages and tutor transcripts.
- Code you write and answers you give.
- Provider URLs and model names.
- API keys and access tokens.
- Repository ids and file paths.
- Free-form notes.
